# GWTC-3 Systematics Audit: Mass Inflation and Phase Impedance

## Overview

This repository contains the analytical framework, Python scripts, and empirical diagnostic tools accompanying the methodological manuscript: **"Directional Systematics in Gravitational-Wave Parameter Estimation: Mass Inflation and Phase Impedance in the GWTC-3 Catalog"** by Jean C. Cortez.

Recent population analyses of the LIGO-Virgo-KAGRA (LVK) catalogs report a statistically significant accumulation of binary black hole chirp masses peaking near $35 M_\odot$. While often attributed to hierarchical mergers, this repository provides a purely mathematical and algorithmic audit to test an alternative hypothesis: **calibration bias via parametric degeneracy**. 

The code herein demonstrates that standard Bayesian inference pipelines (using Inspiral-Merger-Ringdown templates) are highly susceptible to unmodeled macroscopic phase impedance. We show that a phenomenological dispersive phase-drag truncates the frequency-domain ringdown, forcing matched-filtering algorithms to mathematically absorb this early spectral termination by artificially inflating the inferred chirp mass by approximately $+3.52\%$.

## Repository Structure

* `Cortez_GWTC3_Systematics.pdf`: The main methodological manuscript detailing the theoretical derivations, Bayesian likelihood overlap analysis, and the Jacobian destacking proofs.
* `01_imr_parametric_degeneracy.py`: The core mathematical engine. It calculates the expected algorithmic mass inflation required to maximize the Fitting Factor when an IMR template confronts a dispersively truncated waveform.
* `02_phenomenological_baseline_extrapolation.py`: A supplementary diagnostic script that extrapolates a macroscopic phase-drag coefficient ($\beta_{disp} \approx 0.034$) from cross-messenger optical dipoles (SDSS) and calculates the required Lorentz-violating suppression scale ($M_{LV}$), demonstrating compatibility with local limits.
* `03_jacobian_destacking_diagnostic.py`: The empirical projection tool. It extracts raw primary masses from the GWTC-3 catalog, computes observational chirp masses, applies the theoretical Jacobian destacking transformation, and plots the morphological shift using Kernel Density Estimation (KDE).
* `GWTC-3-confident.csv`: The official public data release subset used solely for the macroscopic demographic projection in Script 03.
* `fig1_mass_destacking.pdf`: The output high-resolution diagnostic plot generated by Script 03.
